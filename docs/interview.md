# 대시보드 인터뷰 기록

## 1차 (2026-10-21)
- 데이터: 청구 + 폐암 둘 다, 탭 분리
- 사용자: 개인 학습/탐색
- 인터랙션: 필터 중심 (브라우저에서 계산, 서버 없음)
- 스택: 바닐라 JS + Chart.js

## 2차
- 청구 탭: 상병 Top N, 처방 성분 분석
- 폐암 탭: 치료 패턴 (항암 목적별 건수, 수술 종류, 방사선 여부)
- 필터: 기간(월/연도), 병기/치료목적
  - 주의: 병기/치료목적은 폐암 탭 전용 필터. 청구 탭 필터는 기간만.

## 3차
- 상병 Top N: 4단 코드, 건수↔진료비 토글
- 처방 분석: 상병×약 교차 (상병 선택 → 해당 상병 처방 성분 Top N)
- 폐암 치료 패턴: 환자 수 기준
- 디자인: 깔끔한 분석 도구 톤 (라이트 + 다크 자동)

## 목적 재정의 (2026-10-21, 4차)
- 사용자: 식약처 보건의료분석 담당자. 이전 "개인 학습" 답을 대체한다.
- 가설: 빈부격차로 병원별 진료비 차이가 커졌다는 이야기를 주기적으로 확인하고 싶다.
- 관심 영역: 감염병, 특히 호흡기 질환 딥다이브.
- 데이터 확인 결과: J(호흡기) 주상병 13,285건 / 16개 코드. 법정감염병 표기 코드는 인플루엔자(J101, 4급) 409건, 코로나(U071) 4건뿐.
  소득 5분위별 외래 호흡기 평균 진료비는 22,317~24,249원으로 거의 동일(합성 데이터). 종별 차이는 의원 18,839 / 병원 22,929 / 종합 32,602 / 상급종합 56,137원.

## 5차 (식약처 호흡기·진료비 격차)
- 비교축: 기관 종별, 소득 5분위·의료급여 (권역, 기관 간 편차는 제외)
- 금액 지표: 1건당 진료비 총액, 보험자부담금
- 질환 범위: 호흡기(J) 전체 + 인플루엔자(J101)/법정감염병 강조. 폐암 탭은 이번 범위에 포함하지 않음(미선택)
- 약 분석: 포함. 항생제·약효군 모니터링 (처방률, 약효분류별 금액, 종별 처방 차이)

## 6차
- 중증도 보정: 상병 고정 비교가 기본, 전체(보정 없음) 비교 토글
- 진료 범위: 외래 중심(격차 차트), 입원은 별도 요약(건수·평균 카드)
- 갱신: data/raw 교체 후 `make clean && make raw db data`
- 공유: 회의에서 화면 직접 시연 → 가독성 중심, 큰 글씨, 인쇄/PDF 불필요
- 인터뷰 종료. 이후 구현.
